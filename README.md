# WunderUI plugins for Claude

| Plugin | What it does |
| --- | --- |
| [figma-mobile-dark](figma-mobile-dark) | Mobile (390 px) and dark versions of your Figma screens, derived through variable modes |

## Install in Claude Code

```text
/plugin marketplace add Kl-webmedia/wunderui-plugins
/plugin install figma-mobile-dark@wunderui
```
